## Decisions

- Supabase의 `date` 컬럼과 앱 내부 날짜 계산은 `YYYY-MM-DD`를 계속 사용합니다. 표시 형식을 데이터 형식으로 바꾸면 정렬·기간 계산·기존 데이터에 불필요한 위험이 생기기 때문입니다.
- 화면에 보이는 기준 형식은 `M/D/YYYY`로 정하고, 입력 시에는 앞자리 0이 있는 `MM/DD/YYYY`도 허용합니다.
- 기기와 브라우저 지역 설정에 따라 표시가 달라지는 네이티브 날짜 입력 대신 공통 텍스트 입력을 사용해 앱이 정한 입력 순서를 일관되게 유지했습니다.
