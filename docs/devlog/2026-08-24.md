# 2026-08-24 Inventory Tracker Development Log

## Work Summary

제품마다 최근 사용 인원에 따라 통계 기준이 1인 또는 2인으로 달라지던 계산을 정리했다. 앱의 실제 사용자는 한 명이고 공동 사용은 일시적인 소비 속도 변화라는 요구를 기준으로, 모든 사용·소비·소진·구매 계산을 1인 소비 기준으로 통일했다.

## Work Completed

- 완료된 개봉·소진 주기는 실제 사용 기간에 당시 사용 인원을 곱해 1인 환산 기간으로 계산하도록 변경했다.
- 현재 개봉 제품은 경과일에 현재 사용 인원을 곱해 이미 소비한 1인 환산 일수를 차감하도록 수정했다.
- 1인 환산 사용 주기를 월평균 소비량, 연간 필요량, 소진 예측과 구매 추천의 공통 근거로 사용하도록 기존 계산 흐름을 유지했다.
- 상세 통계의 `1인 사용량` 표기를 `하루 사용량`으로 정리하고, 사용 기록의 실제 인원 표시는 유지했다.
- 현재 저장 인원이 2명이더라도 완료 기록이 1인 기준으로 계산되는 경우와 현재 2인 사용의 경과량 차감을 회귀 테스트에 추가했다.
- `CONTEXT.md`, 프로젝트 요구사항 분석과 ADR에 사용 인원과 개인 소비 기준의 의미를 기록했다.

## Decisions

- 사용 인원은 제품의 통계 기준을 정하는 설정이 아니라 특정 개봉 제품을 몇 명이 함께 사용했는지 나타내는 관측값으로 정의했다.
- 통계와 예측은 항상 앱의 단일 사용자 기준으로 유지하고, 2인 사용 기록은 달력상 기간을 두 배의 1인 환산 기간으로 바꾸는 데 사용한다.
- 기존 Supabase 필드와 기록은 사실 데이터로 유효하므로 스키마나 운영 데이터를 변경하지 않았다.
