## Work Summary - 소비 학습과 계절성 원칙 재정립

수동 사용 월과 과거 구매량을 소비 계산에 함께 사용하면서 실제 사용 시기와 설정값이 어긋나고, 서로 다른 품질의 기록이 하나의 소비 근거로 섞이는 문제가 드러났다. 오늘 논의를 바탕으로 실제 사용을 중심으로 학습하고 계절성은 자동 관찰하는 방향을 운영·계산 규칙에 먼저 확정했다.

## Work Completed - 소비 학습과 계절성 원칙 재정립

- `docs/inventory-rules.md`에 수동 활성 월 제거, 실제 기록 기반 자동 계절성 분석, 첫 완료 주기부터의 임시 추정 원칙을 기록했다.

- 과거 구매 기록은 구매 행동의 참고 자료로 남기되 소비량·소진일의 대체 근거로 사용하지 않는다고 명시했다.

- 결정의 배경과 기존 구현에 미치는 영향을 ADR 0002에 남겼다.

## Decisions - 소비 학습과 계절성 원칙 재정립

- 제품 설정에는 관찰로 알아낼 수 있는 사용 월을 입력하지 않고 실제 사건만 기록한다.
- 완료된 실제 사용 주기 1회부터 표본이 적은 임시 추정치를 제공하며, 기록이 늘수록 최근 표본으로 자동 보정한다.
- 계절성은 연간 총량을 만들기 위한 수동 분모가 아니라 언제 많이 쓰는지를 설명하는 자동 분석 결과다.
- 계절성 통계를 보여주는 기준과 소진·세일 예측에 반영하는 기준을 분리한다.
- 과거 기록의 가치는 날짜가 아니라 의미와 신뢰도로 판단하며, 불확실한 과거 구매량을 실제 사용량으로 복원하지 않는다.
