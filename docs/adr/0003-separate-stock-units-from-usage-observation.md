# 재고 단위와 사용 관찰 방식을 분리한다

제품의 재고는 `병`, `통`, `봉`, `인분`, `개`처럼 실제로 세고 구매하는 단위로 유지한다. `사용량 차감`과 `개봉–소진 주기`는 제품 유형이 아니라 실제 사용을 기록하는 기본 흐름이다. 따라서 모든 제품을 ml·g으로 환산하지 않고, 제품 한 개의 용량은 용량 소비량까지 보고 싶을 때만 선택적으로 보관한다.

제품은 한 시점에 기본 사용 기록 방식 하나를 갖는다. 방식은 진행 중인 개봉 주기가 없을 때 미래 날짜부터 바꿀 수 있고, 과거 사용 이벤트와 완료 주기는 생성 당시 의미로 보존한다. 기존 `tracking_mode=count|cycle`은 호환 기간에 `usage_tracking=decrement|cycle`로 대응시키며, 화면과 계산 전환이 끝날 때까지 삭제하지 않는다.

과거를 모두 복원하지 않아도 예측을 시작할 수 있도록 제품별 회상 소비 기준 하나를 둘 수 있다. 이 값은 대략적인 기간과 총소비량을 가진 임시 예측 근거이며 재고 원장, 실제 사용 표본과 계절성 분석에는 포함하지 않는다. 실제 방식으로 계산 가능한 근거가 생기면 회상 기준은 표시만 유지하고 예측에서는 자동으로 밀려난다.

구매 기록은 가격·수량·구매처·구매 간격의 근거로만 남긴다. 구매량을 소비량으로 추정하는 기존 보조 경로는 화면과 계산 전환 단계에서 제거한다. 반복 할인은 제품별 정기 세일 일정으로 분리해 여러 월·일, 구매처와 행사명을 저장하고, 구매 추천은 현재 기회에서 다음 등록 기회까지의 소비량과 안전 재고를 대상으로 계산한다.

이 결정은 데이터 구조를 먼저 호환 방식으로 추가한 뒤 UI·계산을 전환하고 마지막으로 기존 `active_months`, 단일 세일 필드, `tracking_mode`를 제거하는 단계적 migration을 요구한다.
